## Project Description
### Domain "Productivity"
[Project description]
 - This application is a desktop application where you can budget time. The main page the application would be a dashboard with a metric (pie graph / bar graph) of the time spent for every activity you log. At the menu bar on the right, here is a Punch In & Punch Out button, as well as the activity name. You can also view the time usage weekly and monthly (similar to how you can view your screen time on your phone). The purpose of this app is for people to accurately know one's usage of time and if they notice any unnecessary usage of their time and are busy, they can decide to change how they use that time from what they normally did.
